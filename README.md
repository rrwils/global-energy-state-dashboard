# Global Energy State Dashboard

This project is a React + D3 data visualization app focused on exploring global energy data through an interactive dashboard.

It is part of the **D3 Loves React** course and serves as a hands-on project for learning how to build reusable and responsive chart components, scales, and axes in React using D3.

## What this project covers

- Building chart components in React with D3 logic
- Working with axes
– Making charts responsive
– Adding hover effects

## Run locally

Install dependencies and start the development server:

```bash
npm install
npm run dev
```
